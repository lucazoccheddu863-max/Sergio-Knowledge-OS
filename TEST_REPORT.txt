▶ DESIGN DECISIONS
────────────────────────────────────────────────────────────────────────────────

 1. Chunking is domain logic (strategy pattern) — stays in domain layer
 2. Pipeline is application orchestration — uses AIService, EventBus, Config
 3. Batch size configurable via hierarchical config (m4.embedding.batch_size)
 4. Events decouple embedding completion from downstream consumers (M4.4)
 5. ParagraphChunking falls back to FixedSizeChunking for oversized paragraphs
