▶ DESIGN DECISIONS
────────────────────────────────────────────────────────────────────────────────

 1. All adapters use urllib.request (stdlib) — zero external HTTP dependencies
 2. Embeddings unavailable for Kimi and Claude — raise NotImplementedError
 3. HTTP calls fully mockable for testing (no network in tests)
 4. Provider registry supports runtime registration for extensibility
 5. AIService uses `Any` type for registry to avoid direct adapter imports
    in Application layer (architecture rule compliance)
